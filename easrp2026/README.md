# EASRP 2026 submission pack

Upload this whole folder to Overleaf (or keep `easrp2026.sty` next to `main.tex`).

| File | Role |
|------|------|
| `main.tex` | Anonymous paper (≤8 pages main text) |
| `easrp2026.sty` | Fallback style matching the template commands |
| `references.bib` | BibTeX (natbib / plainnat) |
| `figures/` | All paper figures |
| `WHAT_TO_CHECK.txt` | Compile / anonymity / numbers checklist |

If organizers shipped an **official** `easrp2026.sty`, keep theirs and only use our `main.tex`, `references.bib`, and `figures/`.

**Overleaf:** pdfLaTeX → Recompile twice (BibTeX). Do not switch to `[accepted]` until after acceptance.
